# Normas vigentes (fonte oficial)

PDFs oficiais das normas usadas nas regras do agente médico. Fonte única:
Gov.br/MTE (Normas Regulamentadoras Vigentes) e Gov.br/Fundacentro (biblioteca de
NHOs). Não usar cópia de terceiros nem texto em consulta pública.

**Nome fixo, sem data.** Quando a norma for atualizada, substitua o arquivo no mesmo
caminho. O histórico do git guarda a versão anterior e permite dizer qual texto
sustentava cada regra em cada data.

Estrutura sugerida:

```
normas/
  NR-07.pdf
  NR-09.pdf
  NR-15/Anexo-01-ruido.pdf
  NR-15/Anexo-03-calor.pdf
  NR-15/Anexo-11-agentes-quimicos.pdf
  NR-15/Anexo-12-poeiras-minerais.pdf
  NR-15/Anexo-13.pdf
  NR-15/Anexo-13A-benzeno.pdf
  NHO/NHO-01-ruido.pdf
  NHO/NHO-06-calor.pdf
  NHO/NHO-08-aerodispersoides.pdf
  NHO/NHO-09-vibracao-corpo-inteiro.pdf
  NHO/NHO-10-vibracao-maos-bracos.pdf
```

Para enviar pelo site do GitHub: abra esta pasta, clique em **Add file → Upload files**
e arraste os PDFs. Para uma subpasta nova (ex.: `NR-15/`), use **Add file → Create new
file** e digite `NR-15/LEIA.md` no nome — a barra cria a pasta.
